# Asquilín

![Asquilín](specimen/images/asquilin-cover.jpg)

**Asquilín is a serif typeface designed for long-form reading at compact sizes.**
The name comes from a Tapatío term used to refer to tiny ants: small, persistent creatures capable of quietly taking over entire surfaces.
Designed for text, Asquilín explores readability, rhythm and texture at small sizes.

## About
Asquilín is a text typeface developed around the idea of collective reading.
Its forms are designed to work together rather than stand out individually, creating a consistent texture across long passages of text.
Like the colonies that give it its name, Asquilín is small, persistent and quietly expansive.

## Features
- Serif typeface
- Variable axes: Weight and Optical Size **wip**
- True italics
- Optimized for compact sizes, but still cute
- Extended character set
- Tabular & Oldstyle numerals
- Basic Latin
- Latin Extended — Western Europe
- Latin Extended — Central Europe
- More language support in development
